# Медицинский портал

Учебное ASP.NET Core MVC-приложение на C# с доменной моделью медицинского портала и консольным меню.

## Запуск веб-приложения

```powershell
dotnet run
```

Откройте адрес, указанный в выводе `dotnet run`.

## Консольный режим

```powershell
dotnet run -- --console
```

Меню позволяет просматривать пациентов и врачей, выполнять поиск, записывать на приём, подтверждать и отменять записи, смотреть статистику и оформлять оплату.

## Возможности

- Пациенты, врачи, отделения, услуги, приёмы, медицинские карты, анализы, платежи и рецепты.
- Проверка обязательных данных и неотрицательных значений.
- Поиск пациентов по идентификатору, ФИО и телефону.
- Проверка расписания врача по дате и времени с защитой от двойной записи.
- Статистика пациентов, врачей, приёмов, завершённых приёмов и оплаченных услуг.
- UML-диаграмма и отчёт: [`docs/medical-portal-uml.md`](docs/medical-portal-uml.md).

Демонстрационные данные и изменения хранятся в памяти процесса и сбрасываются после перезапуска. Для постоянного хранения БД пока не подключена.
